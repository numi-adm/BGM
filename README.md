BGM Player

A lightweight, beautiful, and customizable Background Music (BGM) player built with Python and CustomTkinter. Designed to sit in your system tray and control your music seamlessly.

Features

🎨 Beautiful UI: Pastel-themed, soft, and modern hand-drawn style.

🎵 Real-time Audio Control: Adjust volume and playback speed seamlessly without restarting the track.

⏱ Seek Bar: Drag and drop to change the song position.

🔄 Playback Modes: Loop or Shuffle your selected tracks.

🚀 Autostart: Option to launch automatically when Windows starts.

tray System Tray Integration: Minimize to tray to keep your taskbar clean.

Requirements

Windows OS

Python 3.8+

FFmpeg installed and added to Windows PATH.

Installation for Developers

Clone this repository.

Place your MP3 files in the BGM folder.

Make sure you have icon.ico in the root directory for the app icon.

Run the build script to generate the executable:

build.bat
